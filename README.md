# Bottle

An initial responsive landing page concept for a smart-bottle marketing project.

## Preview locally

Open `index.html` in a browser. The page uses plain HTML and CSS; Google Fonts are loaded over the internet and fall back to system fonts if unavailable.

## Project notes

- Responsive marketing landing page with a CSS-illustrated bottle.
- Product feature and capability descriptions are concept copy and should be confirmed against the real product before launch.
- The email form currently opens the visitor's email application; connect it to a mailing-list service before collecting signups.
